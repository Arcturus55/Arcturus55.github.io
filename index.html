Project Experiences

SMILE: Mitigating Object Hallucinations in VLMs via Small Model Assisted Contrastive Decoding and Image Lightweight Editing

Bachelor's Degree Graduation Project, 2025.10 ~ 2026.6

Prior work has explored Contrastive Decoding (CD) to mitigate mulltimodal hallucination. However, these methods suffer from two main drawbacks: suboptimal negative samples and efficiency bottlenecks. To address these limitations, we propose SMILE, a novel framework that improves both the efficiency and effectiveness of contrastive decoding with vision feedbacks.

Automated Workflow Meta Agent Based on Learnware Retrieval and Reinforcement Learning

School-Enterprise Cooperation Project, 2025.5 ~ 2025.9

This project aims to address the need for flexible workflows in tasks requiring diverse capabilities by designing and training a Meta Agent to replace the fixed orchestration logic found in traditional multi-agent systems, thereby enhancing task response adaptability. My responsibilities included researching existing methods (such as AFlow and FlowReasoner), modifying the SearchR1 framework to incorporate agent invocation capabilities, building the Meta Agent training framework, and completing the initial training.

Mitigating Hallucinations in the Rule-Based Reward Process During DeepSeek-R1 Training Utilizing RAG.

2025.3 ~ 2025.5

During the training of the DeepSeek-R1 model, rule-based rewards are employed for the reasoning data component; however, as these rewards rely on heuristic rules, they can potentially introduce hallucinations during the training phase. This project aims to mitigate such hallucinations by utilizing Retrieval-Augmented Generation (RAG). Currently in its early stages, the project involves me testing the performance of R1 and its distilled variants on the HLE and GPQA datasets to verify the existence of these hallucination issues.

Virtual Body: Virtual Human Body Models to Enhance the Efficiency of Clinical Drug Trials

2024.11 ~ 2025.3

Clinical trials are a critical stage in new drug development. This project aims to utilize artificial intelligence methods to model human physiological responses to drugs, thereby facilitating clinical trials for new drug development. My role involved training a reward model based on Deepseek-distill-qwen-7B and—in conjunction with other domestic large-scale models—evaluating and filtering data generated via a diffusion model. This project won the Grand Prize at the "Challenge Cup" National College Student Extracurricular Academic Science and Technology Works Competition.

Addressing the reward model misalignment problem

2024.12 ~ 2025.3

The reward model is a crucial component of RLHF training, representing the human preferences targeted for alignment. However, existing reward datasets are plagued by issues such as erroneous or ambiguous preference signals, which hinder the effective alignment of large models with human preferences. This project aims to validate the existence of these issues by using advanced large models—such as GPT and Gemini—to evaluate preference datasets. By subsequently filtering and augmenting the datasets, the project seeks to enhance the training performance of the reward model.

Extreme Weather Recognition and Prediction Based on LongLLaVA

2024.9 ~ 2025.2

This project aims to develop a multimodal system based on the LongLLaVA model capable of interpreting meteorological charts and forecasting extreme weather events using the information contained within them. LongLLaVA is a large multimodal model utilizing a hybrid Transformer-Mamba architecture, offering robust inference capabilities for multi-image inputs. Leveraging data from the weatherQA dataset, we constructed a training set spanning the years 2014 to 2019 to perform two-stage fine-tuning of the model. Current performance on the test set demonstrates that the model surpasses leading large-scale models such as GPT-4-Turbo and Claude-3-Opus.
